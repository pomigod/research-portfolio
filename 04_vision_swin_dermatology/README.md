# Swin Transformer 10-Class Acne Lesion Classification

**Author**: Jin Hwang (`황진`), Department of Artificial Intelligence, Konyang University
**Research Log Date**: `2025-06-09`
**Blog Archive**: [`https://programmingtrainingkyu.blogspot.com/2025/06/swin-transformer.html`](https://programmingtrainingkyu.blogspot.com/2025/06/swin-transformer.html)
**Original Korean Title**: `Swin Transformer를 이용한 여드름 이미지 분류`

## Summary

Dermatological computer vision project fine-tuning a hierarchical **Swin Transformer** (`Liu et al., ICCV 2021`) to classify 10 clinical acne lesion types (dataset sourced via `Roboflow acne-ovkue/dataset/1`), wrapped in a local interactive desktop classification UI for single-image inference.
